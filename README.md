# roster-analyzer
HR 花名册分析工具 —— 用 SQL 对员工花名册做清洗、结构分析和异常检测。

## 这个项目要做什么
- 把分支机构上报的脏数据（列名不统一、重复行、空值、负数）清洗成一张标准表
- 用 SQL 做部门 / 学历 / 司龄 / 年龄段的分布统计
- 输出异常清单：出勤异常、离职人员仍在考勤表里、部门名与花名册对不上

## 目前进度
- 2026-11-19：建库建表、导入 20 人假数据、基础查询（SELECT / WHERE / ORDER BY / LIMIT）

## 技术栈
Python + SQLite + SQL ｜ 数据全部为虚构假数据，不含任何真实员工信息
